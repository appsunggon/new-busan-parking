# new-busan-parking V4.0 - 카카오맵 지도보기

## 변경 파일
- app.js: 검색 결과 카드에 지도보기 URL 생성 및 버튼 추가
- style.css: 지도보기 버튼 스타일 추가
- index.html: 변경 없음

## 동작
1. 주차장 검색
2. 결과 카드 하단의 [📍 지도보기] 클릭
3. 카카오맵에서 `부산 + 주차장명`으로 검색
4. 공공데이터 주소는 화면 표시용으로만 사용하고 지도 검색에는 사용하지 않음


## 적용
현재 저장소의 app.js와 style.css를 이 파일들로 교체한 뒤 커밋/푸시하면 됩니다.

권장 커밋 메시지:
feat: 주차장 검색 결과에 지도보기 기능 추가


## 지도 방식
- 카카오 공식 지도 검색 링크 `/link/search/검색어` 사용
- 별도 Kakao Maps JavaScript API 키 없이 동작

## 지도 검색 기준 변경
- 기존: 주차장명 + 공공데이터 주소
- 수정: 부산 + 주차장명
- 이유: 일부 공공데이터 주소가 오래되거나 부정확할 수 있기 때문
