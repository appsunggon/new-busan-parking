# new-busan-parking V4.0 최종 - 카카오맵 + 주소 안내

## V4.0 변경사항
1. 검색 결과 카드에 `카카오맵에서 위치 확인` 버튼 추가
2. 카카오맵은 `부산 + 주차장명`으로 검색
3. 공공데이터 주소는 지도 검색에 사용하지 않음
4. 카드의 주소 표기를 `주소(공공데이터 기준)`으로 변경
5. 카드에 `실제 위치와 다를 수 있음` 안내문 추가

## 이유
초기 구현에서는 `주차장명 + 공공데이터 주소`를 카카오맵에 전달했으나,
일부 공공데이터 주소가 실제 주차장 위치와 다르게 검색되는 사례가 확인되었다.

따라서 원본 주소를 임의 수정하지 않고:
- 카드: 공공데이터 원본 주소를 참고정보로 표시
- 지도: 카카오맵 자체 장소 DB에서 `부산 + 주차장명`으로 검색

하는 방식으로 역할을 분리했다.

## 카카오맵 연결 방식
`https://map.kakao.com/link/search/검색어`

웹페이지 안에 Kakao Maps JavaScript API를 삽입하는 방식이 아니므로
이번 V4.0에서는 JavaScript API용 앱키와 도메인 등록을 사용하지 않는다.

## 권장 커밋 메시지
feat: 카카오맵 지도보기와 공공데이터 주소 안내 추가
