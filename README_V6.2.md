# V6.2 변경사항

V6.1의 `search_parking`에 다음 Tool을 추가했습니다.
- `find_available_parking`
- `get_parking_detail`

기본 주차장 API 주소도 실제 배포 주소로 수정했습니다.

`https://new-busan-parking.pages.dev/api/parking`

## 완료 기준
MCP Inspector에서 아래 3개 Tool이 모두 보이고 직접 실행에 성공해야 합니다.
- search_parking
- find_available_parking
- get_parking_detail

아직 Gemini API는 연결하지 않습니다.
